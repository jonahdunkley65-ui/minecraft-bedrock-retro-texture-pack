# Retro Bedrock Texture Pack

A nostalgic texture pack for Minecraft Bedrock Edition that recreates the classic look of early Pocket Edition.

## Installation

1. Download the texture pack
2. Open Minecraft Bedrock Edition
3. Go to Settings > Global Resources
4. Click "My Packs" and select the texture pack folder
5. Activate the pack in your world

## Folder Structure

```
minecraft-bedrock-retro-texture-pack/
├── pack_manifest.json          # Pack configuration
├── textures/
│   ├── texture_set.json        # Texture definitions
│   ├── blocks/                 # Block textures
│   ├── items/                  # Item textures
│   ├── entity/                 # Mob/entity textures
│   └── ui/                     # UI textures
└── README.md
```

## Adding Textures

1. Create PNG files (16x16, 32x32, or 64x64)
2. Place them in the appropriate `textures/` subfolder
3. Update `texture_set.json` with texture references
4. Update `pack_manifest.json` version number when making changes
